## 1. Selection (as committed)

**The pool** was LIBERO-90 kitchen and study scenes. The user chose it after round 1.
- It is the scene family whose LIBERO-10 tasks passed (T4, T5, T7). All four round-1 failures
  were living-room tasks that place two objects.
- Round 1's outcome therefore chose the pool, which is disclosed. Gate 0 filters the curriculum
  for capability. It is not a method outcome.

**The criteria,** the same logic as T5's choice:
- the scene is not in the curriculum, and the four candidates come from four different scenes;
- the moved object is moved by no task in T1–T7 and by no other candidate;
- each slot's backup uses a different action type from its primary.

**The picks are deliberate under these criteria.** The user preferred this to a seeded draw, which
landed on bowls and drawers close to T1 and T3.

**Overlap disclosed in the config:**
- T8 follows T7's template, "put X in a drawer of the cabinet and close it", with a new object,
  a new scene and the top drawer instead of the bottom one.
- T6, "close the microwave", is a short single-step task.

**The data.** Only these four demo files were fetched (`scripts/prepare_libero.py --tasks …`, 3.4
GB), not the ~64 GB suite. Each passed the §3.2 check (50 demos, action statistics).
